Provisioning

Embedded verbatim into every device's setup QR code (both Android's native zero-touch provisioning on stock/GMS devices, and the launcher's own in-app QR scanner for devices like GrapheneOS that need adb-based setup instead). One server and one reusable Tailscale key cover every device - nothing here is per-device.

The tailnet HTTPS URL devices use to reach this server - same value you'd otherwise type into the app's Settings > Server URL by hand.

A reusable pre-auth key generated from your Tailscale admin console - one key enrolls every device via the embedded tsnet client. Leave blank to keep entering it by hand per device instead.

Set on the phone during QR setup (Android's PROVISIONING_LOCALE, form nb_NO). Leave blank to keep the phone's own. adb setup doesn't set it - choose the language in Android's Settings before enrolling. While the phone is managed its language is locked ("Lock the phone's language" under Phone hardening).

Set during QR setup (PROVISIONING_TIME_ZONE, an IANA name like Europe/Oslo). Leave blank to keep the phone's own; automatic time zone is on while the phone is managed.
