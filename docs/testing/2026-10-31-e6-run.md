## Emulator facts learned

- `emulator … -timezone Europe/Oslo` gives the guest that zone (`persist.sys.timezone`), the launcher's automatic time
  zone included; E4/E5's Etc/UTC was the host's.
- The guest clock drifts under host load: 2 minutes behind the host after an hour at load 10-16 (`adb shell date` vs
  `date`); a time rule "for now" needs the phone's own clock.
- `am crash <pkg>` does nothing to the device owner's process; `run-as me.vibb.launcher.debug kill -9 <pid>` (debug
  build) is the way to kill it mid-work.
- The server fetches calendar links itself, so a feed on the host must be reached by the VM's own address
  (`192.168.1.92`), not the emulator's `10.0.2.2`; the server judges a private address as the home network (plain http
  allowed with the warning). A `webcal://` link is https and needs a TLS host.
- `pwam.py`'s `k=v` dict drops repeated fields: a form with several `key=` needs a list-based poster (`pwl.py`).
- A UI dump doesn't show a RecyclerView's `clipToPadding` clip (accessibility bounds stop at the parent's bounds, not its
  padding): Home's fold is read from a `screencap`, column by column. A swipe up on Home from y=750 opens the app
  drawer; short slow drags (80 px, 400 ms) scroll the grid.
- `cmd notification post` as shell is cancelled by the rule; the five `notification_cancel_all` events for gms right
  after a system_server death are the system's, not ours.
