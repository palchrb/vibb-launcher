# r11 glance round - emulator run, 2026-10-24

Branch `r11-glance` after its code QA fix round (16bb4946, 5b071bb3; design `docs/design/r11-launcher-glance-scroll.md`,
review `docs/review/qa-r11-glance-code.md`), the debug launcher of that branch (`0.23.6-debug`) on `jelly36` (the
user's profile: Google Play Android 16, Pixel SystemUI, 480x854 at 240 dpi, `hw.mainKeys = no`, gesture navigation),
main's server (0.43.0, port 3160, debug admin component). A short run (emulator.md §6r): the note's §6 list, items
1-4 and the parts of 5-8 that need no second device. Screenshots in `screens/r11-run/` (emulator console, FLAG_SECURE).

## Setup

- Provisioned per emulator.md §4, enrolled from Vibb One's Settings (the server URL and "Enroll with code" dialogs;
  the "Modify system settings" row from spor B shows "Allowed" there). Android's lock from the PWA (`keyguard=android`,
  Child PIN 1357); contacts Mamma/Pappa/Bestemor; Messages ticked (`apps/toggle` needs `selected=on`) and on the
  glance with text.
- **Messages needs its runtime permissions on a fresh Play image**: `adb emu sms send` was received by the phone
  process (`SmsProvider.delete content://sms/raw`) but Messages wrote nothing to the inbox and posted nothing until
  `pm grant com.google.android.apps.messaging android.permission.{RECEIVE_SMS,READ_SMS,SEND_SMS,READ_CONTACTS,POST_NOTIFICATIONS}`.
  (`pm grant` says "package not found" while the package is still hidden by the enforcer - tick it first and wait a
  sync.) The emulator prefixes the senders with +1, so the rows show numbers, not the contacts' names.
- Rows: 10 SMS conversations (Mamma, Pappa, eight 4790000001-10 numbers) + Bestemor's missed call (`gsm call` /
  `gsm cancel`). No music app installed: the tile rule (§2) is pinned by `LockGlanceTest` and not seen here.
